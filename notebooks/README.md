# Notebooks

Los notebooks anteriores de ranking, BM25, SBERT, qrels y Triplet Loss fueron
retirados porque pertenecían a un alcance distinto. El flujo de Seminario 1 se
ejecuta primero mediante los scripts reproducibles de `scripts/`.

Cuando el dataset binario esté anotado, se podrán agregar notebooks de auditoría
y entrenamiento que lean `data/processed/medical_misinformation_binary.csv`.
Esos notebooks deberán mantener la misma tarea binaria `REAL/FAKE` y no crear
categorías adicionales.
